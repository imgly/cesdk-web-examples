# Import From Figma

Run this Node.js recipe to import a local `.fig` or an accessible Figma REST file and save a CE.SDK archive.

Install dependencies, then run `npm run dev`. Node.js 22.15 or later (23.x requires 23.8+) is required. To use a CE.SDK license, set `CESDK_LICENSE` and uncomment the license setting in `server-js.ts`.

The default input is `assets/sample.fig`, copied from `packages/figma-exporter/src/test/fixtures/fig/capabilities.fig`. It was generated by the exporter, then imported and saved again by Figma. It is a format sample rather than an independently authored Figma design.

Set these environment variables to change the input:

- `FIGMA_INPUT`: local `.fig` path, relative to the process working directory or absolute.
- `FIGMA_FILE_KEY`: Figma file key for REST import; takes precedence over the local input.
- `FIGMA_TOKEN`: token with access to the REST file. Keep it on the server.
- `FIGMA_CANVAS`: canvas name or zero-based index; defaults to `0`.
- `PRESERVE_FIGMA_DATA=false`: omit source-specific metadata; default preservation is enabled.

The recipe writes `output/design.imgly` and `output/import-report.json`. Each import replaces the engine's scene, so save an archive before importing another canvas. Conversion is best effort; review the report for limitations.
